# Каталог наборов «Карточки»

Наборы доступны в приложении через «Наборы карточек» → «Импорт из онлайн-каталога». [Список наборов](https://xururu13.github.io/cards-catalog/)

Чтобы добавить набор, загрузите файл `.yaml` в папку `sets/` и сохраните правку в ветке `main`. Для обновления измените существующий файл и сохраните прежний `id`. Опубликованные файлы доступны всем.

У каждого набора должен быть уникальный `id` из строчных латинских букв, цифр и дефисов. Формат можно сверить с уже опубликованными наборами. GitHub Actions проверяет файлы, пересобирает список и публикует его вместе с YAML. При ошибке проверки продолжает работать последняя успешная публикация.

Проверка на компьютере:

```sh
npm ci --ignore-scripts
npm run build
```
